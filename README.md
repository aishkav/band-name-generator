# Band Name Generator
A beginner-friendly Python project that generates a fun band name based on user input.

---

# How it Works
1. Run the script.
2. Enter the name of the city you grew up in.
3. Enter your pet’s name.
4. Get your unique band name! 🎸

---

# Example Output
Welcome to the Band Name Generator!
What's the name of the city you grew up in? 
London
What's your pet's name? 
Max
Your band name could be: London Max
